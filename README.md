##Descripción
Este proyecto analiza la distribución espacial y topográfica de una huerta a partir de datos KML para optimizar la planificación del riego. Utiliza **Clustering (K-Means)** e interpolación espacial para segmentar el terreno en sectores homogéneos basados en elevación.
